# Google Advanced Data Analytics Professional Certificate

This repository holds coursework and hands-on projects completed as part of Google's Advanced Data Analytics Professional Certificate, a 7-course program covering exploratory data analysis, statistics, regression modeling, and machine learning using Python and Tableau.

## Projects

Diamond Pricing: Exploratory Data Analysis is a project applying the six-phase EDA framework, Discover, Structure, Clean, Join, Validate, Present, to a dataset of 53,940 diamonds. It uncovers a confounding-variable relationship between clarity, carat, and price. Its files live in the notebooks, data, and images folders of this repository.

More projects will be added here as the certificate progresses, each with its own dataset and findings.

## Tools

Python, pandas, seaborn, matplotlib, scikit-learn, Jupyter, Tableau
